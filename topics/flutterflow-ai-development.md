# How to Build Mobile or Web Apps Using FlutterFlow with AI

Previously, there was a significant barrier to developing FlutterFlow applications using AI workflows.

Some developers attempted to overcome this limitation through custom integrations and unofficial approaches.

Now, FlutterFlow has officially launched their MCP server, providing a more definitive solution for AI-assisted development workflows.

# Online Playgrounds

Collection of browser-based playgrounds and sandbox environments for quick experimentation, testing, and prototyping.

---

## Tailwind Play

- https://play.tailwindcss.com/

Official online playground for testing and prototyping Tailwind CSS layouts and components.

---

## regex101

- https://regex101.com/

Online regular expression tester and debugger with real-time explanations and match highlighting.

---

## Rust Playground

- https://play.rust-lang.org/

Official online playground for compiling, running, formatting, and sharing Rust code directly in the browser. Supports multiple Rust editions, crate dependencies, and code sharing via permalink.
